# Antenne

Moderne IPTV-App für Android TV im Apple-TV-Stil – entwickelt von **Erlin Ramaj**.

- Anmeldung mit **Xtream Codes** (Server-URL, Benutzername, Passwort) oder **M3U-Playlist** (optional mit EPG-URL)
- **Live-TV** mit Kategorien, Favoriten, Vorschau und Jetzt/Danach
- **TV-Programm** als Raster mit Senderlogos
- **Filme** und **Serien** mit Postern, Details, Staffeln und Episoden
- Fehlende Senderlogos werden automatisch gesucht
- Weiterschauen, Suche, mehrere Profile

## Installieren

Direkter Download für den Fernseher:
https://github.com/erlinxrmj/TV/releases/latest/download/Antenne.apk

Die App ist nur ein Player. Inhalte kommen vom eigenen IPTV-Anbieter.
